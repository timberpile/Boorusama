Rules demonstrated
1A complete export can replace selected data as a personal backup; shared collections can instead be updated or merged.
2Shared collections are matched by stable UUID. Individual bookmarks use engine, site, and post ID.
3Every conflict and dependency is resolved before the first persistent write.
4A .bsexport file is always available. Small exports can additionally be copied as the exact file encoded in Base64.
5Exported bookmarks include their stored post details. There is no identity-only bookmark mode.
6A checked collection includes future user-created items; an indeterminate collection is fixed even if every current item is selected. New app-defined export entries never enter existing templates.
7Full export includes profile credentials automatically. Choose data keeps credentials as a separate toggle.
8Templates are local recipes and are not included in any .bsexport. Full export is a built-in preset, not a user template.
