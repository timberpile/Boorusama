What to look for

  • Named folders sit above search cards. Searches in Home have no heading on the root page.
  • Each card shows its owning profile, including inside a folder containing searches from different profiles.
  • The former Add Folder action opens Manage folders. You can also create a folder while moving a search.
  • Deleting a folder warns that it will unpin its searches. Cancel leaves them in place.

Try these flows

Open Favorites, use a card’s menu to move it to [Home], then open Manage folders to reorder or delete a folder. Use a card’s Info action to preview the separately tracked Info-dialog change.
