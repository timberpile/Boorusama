## Implemented behavior and decisions

The immutable `ViewerEntry` boundary supports real Posts and Pool-backed Series/Collections without changing persistent Post/Pool identities, bookmark snapshots, or backup formats. Content identity includes engine, normalized source host, kind and upstream ID; transient source binding captures the exact originating profile, authentication and visibility context; occurrence identity distinguishes repeated references. Entries do not own providers, controllers, mutable load state or restoration callbacks.

One outer horizontal pager remains mounted across Post/group transitions. An explicit displayed-index mapping supplies a compact real-Post list to legacy Post consumers. Group-only sequences need no Post controller; groups do not inherit a fabricated current Post, media transformations, playback controls, or Post details sheets. Preloading skips groups within the displayed-page window. Slideshow pauses before advancing into a group. Group vertical gestures scroll the gallery, and explicit Back remains available independently of Post overlay animation/hiding.

Bookmark navigation snapshots the grid's actual filtered/sorted displayed entries. Both Post and Pool cards open that sequence at the displayed index. Membership mutations cannot replace an established viewer occurrence. Existing raw selection, membership, Undo and downloads retain their existing model.

Grouped Search uses the existing `SearchSeriesGrid` projection owner for both grid and viewer. Opening the viewer freezes its established display occurrences; live append uses explicit occurrence and raw/display index mappings. Refresh, controller, query and profile generations cannot append replacement results into an older route. Existing rolling lookahead, Series precedence, raw selection, explicit Pool/Series searches and bounded pagination remain.

Danbooru registers a small engine capability for rendering Pool entries; shared Core does not load Danbooru Pool data. Pool metadata loads lazily with cancellation and localized unavailable/retry feedback. Resolving the bound source rejects deleted, changed-authentication or changed-visibility profiles rather than selecting another account on the same host.

Standalone and embedded Pool pages share `PoolDetailContent`: title, description, updated metadata, actions, Ordered/Latest/Oldest controls and the ordinary filtered/paginated Post grid. Embedded pages omit the standalone AppBar. Sort, scroll and member controllers are local to each occurrence. Eviction retains only route-local order and an offset/page/per-page checkpoint. Reload cannot exceed the previously visited page bound, pauses on errors/inactive routes, and user scrolling cancels restoration. No persistent member snapshot or new fixed cache cap was introduced.

Members open the normal Post viewer with their member sequence and hero transitions disabled. Its exit does not scroll the underlying gallery to the selected member. Navigation activity suspends background playback, shortcuts, automatic viewport fill and refresh actions. Gallery selection locks outer swipes and outer keyboard navigation; cleanup releases only its owned locks.

Architecture details: [Post architecture](../post_architecture.md). The accepted scope has no fundamental architectural or product deviation. Related groups, Pixiv Work presentation, vertical viewer navigation and unrelated redesigns remain outside this change.
