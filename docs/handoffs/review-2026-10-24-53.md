## Corrections

Cancellation cleared the queue but did not invalidate an in-flight result. If
its key was requested again before completion, the canceled result entered the
new cache and suppressed the new loader. A cancellation generation now prevents
that publication while retaining serial admission and shared-future ownership.

The unresolved-media path bypassed the Original exclusion used after metadata
resolution. A stored thumbnail aliasing Original could therefore start an
Original download before metadata finished. Both paths now use the same helper;
unresolved metadata permits only a distinct thumbnail, never a guessed sample.

`preload_metadata_restart_test.dart` adds controlled-completer restart coverage
and unresolved-rendition regressions. Existing queue/rendition tests are retained.
