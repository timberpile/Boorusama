## Correction

The branch delegated bookmark selections to shared actions, but one unresolved
origin or bulk-unsupported source sent the entire selection through the legacy
Original-only fallback. That silently lost ordinary quality/filename policy for
otherwise supported sources. Shared actions now partition by source capability:
normal groups use their normal notifier, resolved fallback groups retain their
own download config, and only unresolved snapshots use the existing credential-
free source fallback. All operations are captured before the first await; no
selected group is silently discarded. A missing filename builder also selects
the stored fallback rather than silently aborting an apparently supported item.

Added a headless action-consumer regression with equal IDs across sources for
both orphan and unsupported-bulk selections. It checks actual normal-download
requests, exact fallback members, source config and unchanged active profile.
The toolbar's explicit PostOriginResolver was also inspected; it does not borrow
the active profile's authentication.
