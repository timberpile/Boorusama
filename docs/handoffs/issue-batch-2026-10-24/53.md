## Implementation

The mixed viewer (also used by Gelbooru-v2 search) recognizes an optional thumbnail-only metadata capability implemented by the Gelbooru-v2 repository. It reuses the same `gelbooruV2PostProvider` future as the visible detail loader. The loader is a deferred callback: inspecting capabilities never initiates requests.

A serial queue considers the current post first and up to four nearby indices from the existing directional strategy, prioritizing nearest posts and then the browsing direction. Direct jumps do not resolve speculative neighbors. New windows replace queued work, cache/failed-attempt entries are bounded by that window, inactive/disabled/disposed viewers stop admitting work, and old results are ignored. An in-flight shared future is allowed to complete because the visible post may await it; this is not claimed as HTTP cancellation. The visible loader remains independent of the speculative queue.

Resolved non-original display images go through the existing directional/grouped image manager. Original-only or unverified renditions retain actual thumbnails; guessed larger listing URLs are not passed as safe thumbnails. Video buffering is unchanged. Post replacements and profile changes reschedule the current plan after the frame. Other engines without the capability retain their existing path.
