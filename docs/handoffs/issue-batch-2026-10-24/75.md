## Implementation

Group and folder covers share the same preview widget. It now subscribes to the existing global GIF autoplay setting. Disabled GIF playback selects a known static thumbnail or sample, never the GIF original. Without a proven static rendition it renders an empty lightweight tile and creates no BooruImage/network request. Ordinary images and video posters retain their prior selection. Enabled GIF previews retain the old behavior; #81 is deliberately independent.

Conservative policy: unknown/extensionless and potentially animated WebP/AVIF preview URLs are not treated as proven static GIF posters. The original URL is excluded even if its suffix claims a static format. No image is downloaded merely to freeze its first frame.
