# Issue #73 — Bookmark bulk group actions

Branch: `feature/73-bookmark-bulk-group-actions`
Base: `6875e0ce778aecfb2b83780c2185ce9273a9b2cc`.

## Implemented

A direct Remove entry is added to the existing Bookmarks selection popup for a named or Default Group, not All Bookmarks. It uses the listing's actual group ID rather than the globally active target, snapshots selected posts before awaiting, and calls the existing source-aware `removePostsFromGroup` operation. The existing removal/Undo mechanism owns membership semantics. Add/remove group pickers remain available. There is no permanent-delete path or new persistence.

The existing popup is deliberately reused: `MultiSelectionActionBar` extracts metadata only from direct MultiSelectButton/MultiSelectPopupButton children; an arbitrary wrapper would become a nonfunctional Button entry on overflow. This implementation does not add such a wrapper.
