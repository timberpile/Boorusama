# Issue #76 — Realbooru original metadata

## Changes and limits

The existing detail HTML parser now keeps the displayed image as the sample and resolves explicitly identified original links/data attributes separately. It parses original dimensions only from explicit attributes or labeled post-info text, not resized img dimensions. Exact byte counts can travel through a new nullable DTO field into the existing Post record. Unknown facts retain the existing operational sentinel in Post; no public nullable-model migration is attempted. Rounded KB/MB values are deliberately not invented as exact bytes. Video handling and listing parsing are unchanged. No additional requests, HEAD requests or full media downloads are introduced.

The original HTML fixture in this repository only covers a direct image. The new tests use synthetic markup contracts, **not captured live-host proof**. Actual Realbooru Original-link/stat markup must be captured and checked locally before acceptance. Support currently recognizes highres/original-image/original-file anchor IDs, explicit Original labels and image data-original attributes. Conflicting/unsafe original references and known /samples/ URLs without an original remain unavailable rather than silently treated as originals. The existing direct-image fallback is retained for pages without an explicit original reference.
