## Changes

The native backup channel now reports a bounded operation stage and exception type, with stack locations but without exception messages, document URIs, source paths, payloads or credentials. Only `SecurityException` is classified as a permission failure; programming/validation failures are no longer falsely classified as folder permission errors. Cleanup failures no longer replace the original copy/verification exception. Existing backup verification, manifest ordering and retention behavior are intentionally unchanged.
