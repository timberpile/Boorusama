# IDEA-020 — Vertical comic navigation

Priority: Normal
Feature: Vertical post viewer, `feature/20-vertical-comic-navigation`

## Problem

Vertical paging competes with panning an auto-fitted or manually zoomed comic. The visible arrow overlay was not the intended navigation model; readers need a deliberate image-edge handoff that keeps media gestures intact.

## Expected behavior and acceptance criteria

- On a manually zoomed or Auto Comic fitted image, PageView remains non-scrollable and the image keeps pan/pinch ownership. A single horizontal-dominant touch/stylus drag can navigate only after the displayed image reaches its true left/right clamp and travels at least 160dp farther outward; at most one page changes on pointer-up.
- Vertical scrolling, pinch/multi-pointer, reversal, cancellation, subthreshold movement, unzoomed images, expanded details, notes, and video do not trigger the handoff. It works with the toolbar hidden or shown, on small and large layouts, and follows PageView RTL direction.
- A compact hollow ring at the relevant viewport edge fills with a valid outward pull and fades from transparent to opaque during its first half. It stays armed at 100% until release, then hides. No permanent Item-20 arrow appears. Retry and Load more have distinct icons and semantic labels; unavailable actions never show a misleading ring. Pre-existing desktop navigation and bounded screen-reader actions remain.
- Existing double tap, details/video controls, desktop controls, keyboard/volume navigation, and Auto Comic per-visit fitting remain usable. Android Maestro validates reachable touch behavior without clearing app data.

## Dependencies and constraints

Uses existing auto comic detection and `PostDetailsPageViewController`. No dependency on other open ideas. The mixed viewer keeps one shared details/page controller and ordered mixed-source posts. Its grid-backed route now receives a narrow append-only source with actual loading completion; fixed-list entry points remain snapshots. No lazy-route switch or second navigation state machine.
