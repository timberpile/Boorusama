## Requirements and implementation

Undo feedback must sit just above visible bottom navigation, selection controls, viewer preview or keyboard, with correct movement when navigation chrome hides and with a reachable action. The change replaces a fixed 100-pixel offset for action toasts with an overlay-local bottom-inset value and live `ValueListenable`. The shell supplies a stable feedback context, while selection/footer and viewer preview publish measured obstructions; regular toasts without actions retain prior positioning. Action hit target now has 48×48 minimum size.

## Findings

**No separately actionable defect identified in the statically inspected implementation at this revision.** The new inset scope takes the actual visible navigation height or measured selection/viewer obstruction with system bottom padding, and live toasts subscribe to that value rather than retaining the opening position. The shell wraps the destination Navigator in the inherited scope and `feedbackKey` gives asynchronous bookmark removal callbacks a descendant context. The 48×48 Undo action and owner-aware selection/viewer state are present. These are source observations, **not** executed tests, and do not prove pixel-perfect device behavior.
