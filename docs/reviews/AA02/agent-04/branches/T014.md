## Findings

**No actionable defect established in inspected source paths.** The filter identity includes sort and yields new immutable projected order; activating even sort-only mode stops existing history and blocks `fetchMore` from requesting older pages. Closing Search resets the filter and restores the stored order; the applied sort touches only snapshot copies. Bookmark score comparison is local and deterministic and the enum appended values preserve existing enum ordinal identities. Unknown legacy metadata gets explicit stable fallback instead of network requests. This is not an absence-of-bugs guarantee.
