## Requirements and implementation

The new GitHub primary action combines download → SHA256/size validation → Android permission/settings → native installer start while keeping Play Store and browser fallback. [AppUpdateDialog](https://github.com/timberpile/Boorusama/blob/9ac4dd73b4c505c9c300a0e5fe43bf1ba0d06d07/lib/foundation/app_update/src/widgets/app_update_dialog.dart#L31-L216) tracks app lifecycle, postpones install until resumed, rechecks permission after returning from Settings, avoids repeatedly opening Settings after denial, preserves cached verified APK, cancels pending downloads and validates modal route ownership. The [existing native APK install policy](https://github.com/timberpile/Boorusama/blob/9ac4dd73b4c505c9c300a0e5fe43bf1ba0d06d07/android/app/src/main/kotlin/com/timberpile/boorusama/GitHubApkInstallPolicy.kt#L1-L33) retains package identity, strictly newer version, expected build/version, signer-set equality and private cache-path restrictions.
