## Implementation and source paths

The issue asks for a visual Toolbar/More placement editor, drag/reorder and accessible move actions, physical right-side More, center retention on small screens, per-engine availability under one global override, native defaults without opt-in and backup compatibility. The [immutable V1 layout model](https://github.com/timberpile/Boorusama/blob/8213b6fbb87cb09d30d5056ad6667821371f22f6/lib/core/settings/src/types/viewer_toolbar_layout.dart) persists named action IDs, limits Toolbar to five slots, ignores duplicate/unknown IDs and appends known missing actions to More; its projection filters by actually supplied actions, preserving preference order while moving outer actions into temporary overflow. [Settings](https://github.com/timberpile/Boorusama/blob/8213b6fbb87cb09d30d5056ad6667821371f22f6/lib/core/settings/src/types/settings.dart#L260-L270) holds a nullable global override not present in profile-specific viewer settings; backup round-trip uses ordinary settings serialization.

[Toolbar editor](https://github.com/timberpile/Boorusama/blob/8213b6fbb87cb09d30d5056ad6667821371f22f6/lib/core/settings/src/widgets/viewer_toolbar_editor.dart) provides inert preview, horizontally scrollable configured slots, long-press/drop, explicit full-row replacement and localized movement controls. [Settings route](https://github.com/timberpile/Boorusama/blob/8213b6fbb87cb09d30d5056ad6667821371f22f6/lib/core/settings/src/pages/viewer_toolbar_layout_page.dart) protects drafts from concurrent settings replacement; Apply persists, Back discards, Reset returns to original engine layout. [Configured renderer](https://github.com/timberpile/Boorusama/blob/8213b6fbb87cb09d30d5056ad6667821371f22f6/lib/core/posts/details_parts/src/toolbars/customizable_post_toolbar.dart) keeps More physically right, captures the source `ProviderScope`, closes stale overlays when callback-bearing widgets change and uses legacy `BooruMenuButtonRow` when not configured. Standard and Danbooru row callers supply typed actions; Moebooru inherits standard. Bookmark/Download/Favorite/Share/vote menu presentations retain existing operations and Danbooru remove-vote support; fixed utility entries remain in More.
