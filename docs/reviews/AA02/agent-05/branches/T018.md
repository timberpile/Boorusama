## Implementation summary

Existing vertical blacklist-only panels remain inline.

[ImageListingSettings](https://github.com/timberpile/Boorusama/blob/5bb52794468b172b7d6878fb825b42b00d654675/lib/core/settings/src/types/settings.dart#L800-L925) adds a new `keepTimelineToolbarVisible=false` persisted field independent of the old `showPostListConfigHeader`, which stays readable from legacy backups; old values are not interpreted as pinning. A small fork-local `Translations.timelineToolbar` bridge supplies German and fallback English descriptions. Issue #115 Search toolbar integration is explicitly out of scope.

Localization is not in the standard Slang JSON catalog; the branch's own handoff flags the fork-local de/en bridge for eventual consolidation.
