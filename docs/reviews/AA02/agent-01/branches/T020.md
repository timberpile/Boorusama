## Static outcome

No independently substantiated new defect. Family session state is isolated per config/account/filter and canceled at disposal or refresh. Capability-aware navigation is only available for configured authenticated accounts, with an auth page fallback when invalid. Tests explicitly cover most pagination/cursor abuse paths.
