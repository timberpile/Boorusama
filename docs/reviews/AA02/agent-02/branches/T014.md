## Findings and caveats

No independently established **introduced** defect. The underlying `PostGridController` computes per-tag matching IDs as `Set<int>` and filters by numeric `post.id`; different-origin posts sharing one numeric ID could therefore be conflated **if** a mixed-origin controller combines them. This is pre-existing in the controller, and a reachable affected grid was not established from this pass, so it is a context note—not counted as a confirmed finding against #114. The new header's count correctly unions active rule IDs rather than summing overlapping matches. The temporary zero-count indicator remains present while matching rules are toggled off.
