## Flow traced

Navigation chrome now reports separate measured selection footer and viewer preview obstructions, with owner-scoped notification. `NavigationOverlayInsetsScope` interpolates the bottom bar's hidden fraction, prioritizes open viewer/selection obstructions, coalesces an external `ValueNotifier` after frame, and publishes both inherited static bottom padding and the live notifier. `KeyedSubtree(feedbackKey)` gives root-navigation Undo callbacks a stable context *beneath* that scope. Kurumi action toasts consume the listenable so existing on-screen Undo adjusts during scroll transitions; non-action toasts retain their old behavior. The media/selection controls measure geometry from layout and remove listeners/dispose notifiers. The tests cover 320px, 1x/2x, safe area, 88/0/44 bar, selection 150/220, viewer 80/0, keyboard + selection, undo action and disabled native media host behavior.
