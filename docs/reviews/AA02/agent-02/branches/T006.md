It deliberately retains recognized user/pool and non-ordinary metatag/option entries, and does not suppress autocorrection by treating it as an alias. Both the mobile suggestions panel and desktop popover listen to selected-tag changes and apply the filter to current profile's fetched candidates; no new network request or mutable cross-profile identity cache is introduced.
