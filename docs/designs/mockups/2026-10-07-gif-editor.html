Boorusama · interface concept

A small clip.
A GIF worth sharing.

Choose the moment, tune the size, then check the result before saving or sharing it.

One entry point. Create GIF stays in the Media section of Share. Regular video sharing remains alongside it.

Interactive mockup. Source metadata, scene, playback, conversion, result sizes, saving, and sharing are simulated. The estimate is calculated from demo metadata with an uncalibrated compression factor; no sample is encoded. No source video is downloaded. Proposed UI only; the Flutter app is unchanged.

Proposed encoding default: full adaptive palette with Sierra dithering; no extra quality slider initially. Size estimation is instant: output width × height × retained frame count × 0.5 bytes. The 0.5 compressed bytes per pixel per frame is a provisional assumption to calibrate on real outputs, not a measured accuracy claim. Display a rounded approximate MB value; never gate creation on this estimate. GIF stores frame delays in 10-ms steps, so high playback rates need timing approximation or fewer output frames. Native UI integration and heuristic calibration remain future work.
