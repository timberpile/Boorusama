What is preserved?

Two modes, not three

Single reuses the existing shared post viewer with Immersive and Detailed states for every site. Timeline reuses the existing Pool/Related group-page presentation, extended to Pixiv Works.

Mode-dependent actions

Two separate Bookmark buttons always appear in Single: the image-badged button saves the current Post/Page; the stack-badged button saves the entire Work/Pool/Series/Related Group. Both use independent folder selections. Favorites (heart) are site-dependent and stay separate.

Natural initial presentation

Pixiv Works, Danbooru Series and Related Groups open Single by default. General Pools/Collections retain Timeline by default. An explicit switch does not reorder members.

No permanent outer-feed rail

The new study removes the earlier prototype's extra navigation strip, standalone group header in Single and mandatory mode row.

Group information

Post Details retain existing Pool/Series links; descriptions stay in the group Timeline. Pixiv Detailed retains Work metadata. No new expandable Group-info card is added.

Ordering

Pool retains its existing sort choices; Related uses Oldest/Newest in both Single and Timeline, and a bookmarked Related Group remembers this selection. Series uses Ordered; Pixiv retains author page order.

Prototype graphics are original stand-ins. Supplied screenshots are layout references, not redistributable fixture assets.
