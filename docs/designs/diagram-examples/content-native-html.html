Aspect-ratio behavior is a layout decision, not a Group type

A wide image fills available width; normal images are comfortably fitted; extremely tall images need a bounded overview while Image View retains the reading/zoom position.

Prototype for structure discussion, not application implementation. The sample photography is loaded from Unsplash. Remote image requests reveal the viewer's IP address to the image provider; offline or hotlink-blocked images display a fallback.
